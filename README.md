# ASTERIA II — Horizon Bridge v2.0

아스테리아-2 심우주 항해 시뮬레이션. 서버·API 키·CDN·npm 설치가 없는 정적 사이트입니다. 전후좌우 및 상하 360° 관측을 지원합니다. WebGL 3D 관측 구역에서는 천체 표면을 실시간으로 렌더링하고, 우주 시야에 함교 내부 WebP를 합성합니다. 관측 위치는 함교 중앙에 고정되며, 함교를 걸어다니는 6DOF 게임은 아닙니다.

## 시작하기

- ZIP을 압축 해제하고 `index.html`을 브라우저에서 여세요. 모든 상대경로 에셋을 같이 유지하세요. 브라우저의 로컬 파일 접근 정책에 따라 정적 HTTP 호스팅이 필요할 수 있습니다.
- GitHub Pages: 저장소 루트에 `index.html`, `app.js`, `space.js`, `style.css`, `.nojekyll`, `assets/`를 업로드합니다. Settings → Pages → Deploy from a branch → main / (root) → Save.
- 별도 빌드 과정 없음. 일반 정적 호스트 또는 로컬 `python -m http.server 8000`으로도 실행할 수 있습니다.

## 조작법

| 입력 | 기능 |
|---|---|
| WASD / 화살표 | 상하좌우 연속 회전 (각도 제한 없음) |
| 마우스 / 터치 드래그 | 시야 회전 |
| Q/E | 롤 360° |
| 마우스 휠 / +, - | 시야각 확대/축소 |
| R / 더블 클릭 | 정면 복귀 및 롤 초기화 |
| C / Esc | 관측 모드 / 종료 |
| 자동 시야 | 일정 속도로 수평 자동 회전 |
| 함교 ON/OFF | 3D 함교 구조 표시/숨기기 |
| 항해 → | 선택한 목적지로 워프 |
| 관측 항로 | WebGL 3D 구역에서 먼 위치(0%)와 가까운 위치(100%) 사이를 이동. 네레이드에서는 고리 평면 통과 |
| 우주 상황 | 선택한 12초 상황 재생; 자동 상황을 켜면 간헐적으로 발생 |

## 탐사 구역 (9)
NEREID(고리형 가스 행성), SELENE(빙하 행성), EOS(암석 행성), DEEP SPACE(심우주), GAIA(지구형 행성), SOLARIS(항성), SINGULARITY(블랙홀), ASTEROID BELT(소행성대), NEBULA(성운).

우주 상황 6종: 유성우, 소행성 통과, 혜성 조우, 태양 폭풍, 미확인 신호, 탐사선 조우. 레이더·보호막·항해 속도는 시뮬레이션 수치입니다.

## 렌더링

- WebGL 3D 관측 구역은 네레이드, 셀레네, 이오스, 가이아, 솔라리스, 특이점, 소행성대입니다. 천체의 위치와 반지름을 기준으로 시선과 표면의 교차점을 계산합니다. 렌더러가 자전·위성 공전, 천체와 고리의 가림과 그림자, 대기 가장자리 산란광을 계산합니다. 특이점의 강착원반과 배경을 휘게 하는 중력렌즈는 시각적 근사입니다.
- 관측 항로는 카메라의 우주 공간 좌표를 이동시키므로 가까운 천체와 위성이 먼 별 배경에 대해 시차를 보입니다. 확대/축소는 별도로 시야각을 바꿉니다. 네레이드의 고리를 통과한 뒤에는 시야를 돌려 행성을 다시 관측할 수 있습니다.
- 심우주와 성운에는 WebGL 큐브맵을 씁니다. 3D 셰이더나 추가 에셋을 사용할 수 없는 구역은 기존 WebGL 큐브맵을 표시합니다. GPU 컨텍스트를 생성할 수 없거나 실행 중 손실되면 Canvas로 전환합니다.
- 동작 줄이기 설정에서는 천체가 자동으로 움직이지 않습니다. 수동 시야 회전과 관측 항로 조작은 계속 사용할 수 있습니다.
- Canvas 360°: 화면 픽셀을 시야 방향에 따라 6면 텍스처로 역투영하여 실제 전방위 연속 시야 제공. 움직일 때 낮은 렌더 해상도, 정지하면 높은 렌더 해상도. WebGL 없는 브라우저에서도 동작.
- 함교와 우주를 별도 레이어에 렌더링해 동적 이벤트가 창문 뒤로 나타납니다. 360° 회전은 시야 방향을 바꾸고, 관측 항로 이동은 구역별 경로를 따릅니다.
- 8192×4096 성운·별 파노라마 원본, 4096×2048 표면 텍스처 5개, 1536×1536 우주 큐브맵 54개, 2048×2048 투명 함교 큐브맵 6개. 8K 파노라마 원본은 에셋 제작에 사용합니다. WebGL 3D 구역은 기존 4K 표면 텍스처를 필요한 때 불러옵니다.
- 에셋은 절차적 합성 및 3D 기하 렌더링으로 자체 제작한 허구의 천체 이미지이며 실제 NASA 사진이나 정확한 천체물리 시뮬레이션이 아닙니다.
- Python 제작 스크립트: `assets/build_v2.py`, `assets/render_bridge.py` (Python/Pillow/NumPy/SciPy 필요). 실행에는 Python이 필요하지 않습니다.

## 검증 범위

브라우저 회귀 검사는 로컬 정적 서버의 하위 경로에서 실행합니다. Playwright와 Chromium을 설치한 환경에서 `python tests/browser_smoke.py`를 실행하세요. 설치된 Chromium 바이너리를 지정하려면 `CHROMIUM_BIN` 환경 변수를 사용합니다.

검사 범위는 데스크톱과 모바일 화면, 9개 구역 전환, 3D 시점 이동, 동작 줄이기 설정, 360° 입력, 관측 모드, GPU 컨텍스트 손실, 3D 에셋 누락입니다. 소프트웨어 WebGL로 검사하며 실제 GPU와 실물 모바일 하드웨어는 검증 범위 밖입니다.
