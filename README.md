# ASTERIA II — Horizon Bridge v2.0

아스테리아-2 심우주 항해 시뮬레이션. 서버·API 키·CDN·npm 설치가 없는 정적 사이트입니다. 전후좌우 및 상하 360° 관측을 지원합니다. WebGL 3D 관측 구역에서는 천체 표면을 실시간으로 렌더링하고, 우주 시야에 함교 내부 WebP를 합성합니다. WebGL에서는 창틀, 갑판과 조종석을 깊이 검사를 적용한 3D 메시로 렌더링합니다. 항해 중에는 함교 중앙에서 조작하고, 함교 이동 모드에서는 실내를 둘러볼 수 있습니다.

## 시작하기

- ZIP을 압축 해제하고 `index.html`을 브라우저에서 여세요. 모든 상대경로 에셋을 같이 유지하세요. 브라우저의 로컬 파일 접근 정책에 따라 정적 HTTP 호스팅이 필요할 수 있습니다.
- GitHub Pages: 저장소 루트에 `index.html`, `app.js`, `sky-assets.js`, `sectors.js`, `space.js`, `flight.js`, `bridge-layout.js`, `marie-rig.js`, `marie-motion.js`, `marie.js`, `marie-command.js`, `marie-adapter.js`, `marie-console.js`, `bridge-room.js`, `events.js`, `navigation-map.js`, `bridge-audio.js`, `style.css`, `voyage-store.js`, `voyage-panel.js`, `watch-plan.js`, `manifest.webmanifest`, `sw.js`, `.nojekyll`, `assets/`를 업로드합니다. Settings → Pages → Deploy from a branch → main / (root) → Save.
- 별도 빌드 과정 없음. 일반 정적 호스트 또는 로컬 `python -m http.server 8000`으로도 실행할 수 있습니다.

### 자유 조종

실시간 3D 구역에서 **자유 조종** 또는 P를 누릅니다. WASD는 피치·요, Q/E는 롤을 제어합니다. I/K는 전후, J/L은 좌우, U/O는 상하 이동입니다. Shift/Ctrl로 추력을 조절하고 Space로 제동합니다. **독립 시점**에서는 드래그로 기수와 별도로 주변을 둘러볼 수 있습니다. Esc는 기존 관측 항로로 복귀합니다. 터치에서는 피치·요 스틱, 앞뒤·좌우 스틱과 상하·롤·제동 버튼을 사용합니다.

**보조** 메뉴에서 접근, 공전, 거리 유지, 이탈을 고를 수 있습니다. 다른 구역을 선택한 뒤 **목적지 자동 항법**을 누르면 출항 준비와 워프를 거쳐 도착 후 접근합니다. 출항 준비 중에는 취소할 수 있습니다. 구역 내 좌표와 속도는 시뮬레이션 단위 SU와 SU/s입니다. 파노라마 구역과 Canvas에서도 기존 목적지 이동과 360° 관측을 이용할 수 있습니다.

### 거주형 함교

**함교 이동** 또는 V로 실내에 들어갑니다. 가까운 좌석·콘솔·출입문은 F나 화면 버튼으로 조작합니다. 처음 위치에서 함장석에 앉을 수 있습니다. 후방 중앙 통로를 따라 압력문을 지나면 별을 볼 수 있는 라운지와 좌석이 있습니다. F나 같은 버튼으로 일어나거나 Esc로 관측 시점에 돌아갑니다. Shift/Space로 높이를 바꾸는 기존 조작도 유지됩니다.

좌현 과학 콘솔은 항해 지도를, 우현 통신 콘솔은 음향을 조작합니다. 이동 화면에서 일반/야간 조명과 음량을 선택할 수 있습니다. 함교 음향을 켜면 카메라 위치·방향에 따라 엔진, 순환기, 레이더, 문, 발걸음의 좌우 위치와 크기가 바뀝니다. 구역 광원과 워프 색조는 실내 조명에도 반영됩니다.

### 마리와 함께하는 함교

마리는 3D 함교에서 계기판 점검, 순찰, 관측, 휴식을 번갈아 수행합니다. **마리 → 동행 켜기**를 선택한 뒤 **함교 이동**을 사용하면, 통로와 가구를 피하며 거리를 두고 따라옵니다. **상태 보고**에서는 현재 항로와 관측 상태를 확인할 수 있습니다.

**차 준비**를 요청하면 준비와 대접을 거쳐 **차 받기**가 활성화됩니다. 경보나 워프 중에는 작업을 보류합니다. 미확인 신호나 구조 신호가 들어오면 **드론 파견** 또는 **드론 귀환**을 선택할 수 있습니다. 조사 결과는 모의 데이터로 표시됩니다.

동작 줄이기에서는 위치와 연속 동작을 고정하고 업무 상태와 포즈를 갱신합니다. Canvas에서도 보고·차·드론 기능을 사용할 수 있습니다. [모델과 검증 자료](qa/PR11_REPORT.md)

### 마리와 대화

**마리 → 마리와 대화**에서 “마리, 상태 보고”, “가이아로 항로 설정”, “차 한 잔”, “자동 관측 시작”처럼 입력할 수 있습니다. 항로 설정은 목적지를 지정합니다. 워프와 반복 자동 관측은 화면에서 별도로 승인합니다. “정지”는 대기 중인 요청과 후속 자동 이동을 중단합니다.

기본 대화는 로컬에서 처리합니다. **기억과 외부 응답 설정**에서 선호 구역을 저장·내보내기·삭제하거나, 사용자 관리 HTTPS 프록시를 설정할 수 있습니다. 외부 응답은 입력과 전송 내용을 확인해 승인한 요청에만 사용합니다. [연결 계약 및 검증](qa/PR13_REPORT.md)

### 함교 음향과 자동 관측

음향은 기본적으로 꺼져 있습니다. **음향** 버튼으로 활성화하면 추력에 맞춘 엔진 저음, 생명유지 순환음, 레이더 탐지음과 워프 충전음을 들을 수 있습니다. 3D 함교 이동 중 후방 출입문에 접근하면 문이 열리며 구동음이 재생됩니다.

**관측 모드 → 자동 관측 시작**을 누르면 현재 구역에서 45초 관측한 뒤 지정된 8개 구역을 반복 순회합니다. **다음 구역**으로 대기를 건너뛰고 **자동 관측 종료** 또는 Esc로 함교 조작으로 복귀할 수 있습니다. 음향을 켠 경우 자동 관측 중 낮은 음량의 앰비언트가 재생됩니다. 탭을 숨기면 소리와 다음 구역으로 이동하기 위한 대기를 잠시 멈춥니다.

### 항해 일지·맞춤 자동 관측·오프라인

항해 패널의 **항해 일지**에서 구역 도감, 세션 기록, 백업과 오프라인 구성을 엽니다. 새 항해 기록은 기본적으로 이 페이지에만 유지됩니다. **저장·백업**에서 저장을 켜면 마지막 안전 구역을 복원하고, 기존 방문은 별도 가져오기로 합칩니다. 현재 워프나 자동 실행은 새로고침 후 재개하지 않습니다.

**관측 모드 → 맞춤 항로**에서 구역 순서, 관측 시간, 반복 횟수, 시점과 음향을 설정한 뒤 승인합니다. 기존 8개 구역 45초 자동 관측도 함께 제공합니다.

HTTPS 또는 로컬 HTTP 지원 환경에서는 NEREID 기본 구역을 오프라인에서 열 수 있습니다. 온라인일 때 **오프라인·설치**에서 다른 구역을 내려받으십시오. 저장 및 캐시 정책은 [PR14 검증 보고서](qa/PR14_REPORT.md)에 설명합니다.

### 홀로그램 항해 지도

상단의 **항해 지도**에서 32개 구역을 조회합니다. 드래그 또는 지도에 포커스를 둔 상태에서 방향키로 회전하고, **+ / −** 버튼으로 확대·축소합니다. 구역 필터는 현재 위치와 선택한 목적지를 계속 표시합니다.

구역 점을 선택하면 기존 목적지 메뉴에도 반영되며, 점선으로 예정 항로를 표시합니다. 워프 중에는 도착 방향으로 움직이는 함선 표시와 진행률을 보여줍니다. 항해를 마치면 그 구역을 방문으로 등록합니다. 브라우저 저장은 항해 일지에서 선택합니다. 지도 좌표는 시뮬레이션의 탐사 구역 배치입니다.

상황별 기본 지속 시간은 10~30초입니다. 대응 버튼으로 보호막 부하와 관측 노출을 낮추거나 추가 추적 시간을 확보할 수 있습니다. 자동 상황을 켜면 조건을 충족한 후보가 발생하며, 다른 상황이 진행 중이지 않을 때 고리 경계에 진입하면 고리 통과가 우선합니다. 관측 종료나 워프 시작 시 현재 상황을 정리합니다. 레이더·보호막·항해 속도는 시뮬레이션 수치입니다.

## 렌더링

- 32개 구역 중 30개는 실시간 3D 관측을 지원합니다. 천체의 위치와 반지름을 기준으로 시선과 표면의 교차점을 계산합니다. 렌더러가 자전·위성 공전, 천체와 고리의 가림과 그림자, 대기 가장자리 산란광을 계산합니다. 특이점의 강착원반과 배경을 휘게 하는 중력렌즈는 시각적 근사입니다.
- 관측 항로는 카메라의 우주 공간 좌표를 이동시키므로 가까운 천체와 위성이 먼 별 배경에 대해 시차를 보입니다. 확대/축소는 별도로 시야각을 바꿉니다. 네레이드의 고리를 통과한 뒤에는 시야를 돌려 행성을 다시 관측할 수 있습니다.
- 관측 항로에 카메라에서 천체 표면까지의 거리를 시뮬레이션 단위(SU)로 표시합니다. 소행성대에서는 가장 가까운 소행성의 표면 거리를 표시합니다.
- 기존 DEEP SPACE와 NEBULA 구역에는 WebGL 큐브맵을 씁니다. 3D 셰이더나 추가 에셋을 사용할 수 없는 구역은 기존 WebGL 큐브맵을 표시합니다. GPU 컨텍스트를 생성할 수 없거나 실행 중 손실되면 Canvas로 전환합니다. 천체 표면이나 큐브맵을 GPU에 올리지 못하는 경우에도 해당 구역의 Canvas 파노라마로 전환합니다.
- 실시간 3D 해상도는 화면 크기와 최근 프레임 간격에 맞춰 조절합니다. 프레임이 느려지면 해상도를 낮추고, 부드러운 상태가 지속되면 긴 변 기준 최대 2200픽셀까지 올립니다.
- 초기 필수 에셋 로딩에 실패하면 관측창의 **다시 시도** 버튼을 눌러 같은 페이지에서 복구할 수 있습니다.
- 동작 줄이기 설정에서는 천체가 자동으로 움직이지 않습니다. 접근과 이탈 버튼을 누르면 중간 애니메이션 없이 끝 위치를 표시합니다. 관측 순회에서는 각 단계의 끝 위치를 순서대로 표시합니다. 수동 시야 회전과 슬라이더도 사용할 수 있습니다.
- Canvas 360°: 화면 픽셀을 시야 방향에 따라 6면 텍스처로 역투영하여 실제 전방위 연속 시야 제공. 움직일 때 낮은 렌더 해상도, 정지하면 높은 렌더 해상도. WebGL 없는 브라우저에서도 동작.
- 함교 이동은 실내 통로 범위로 제한합니다. 드래그와 Q/E로 쿼터니언 기반 시야를 조작합니다. 셰이더를 사용할 수 없으면 기존 함교 파노라마로 전환하고 이동 모드를 비활성화합니다.
- 함교와 우주를 별도 레이어에 렌더링해 동적 이벤트가 창문 뒤로 나타납니다. 360° 회전은 시야 방향을 바꾸고, 관측 항로 이동은 구역별 경로를 따릅니다.
- 8192×4096 성운·별 파노라마 원본, 4096×2048 표면 텍스처 5개, 1536×1536 우주 큐브맵 54개, 2048×2048 투명 함교 큐브맵 6개. 8K 파노라마 원본은 에셋 제작에 사용합니다. WebGL 3D 구역은 기존 4K 표면 텍스처를 필요한 때 불러옵니다.
- 에셋은 절차적 합성 및 3D 기하 렌더링으로 자체 제작한 허구의 천체 이미지이며 실제 NASA 사진이나 정확한 천체물리 시뮬레이션이 아닙니다.
- Python 제작 스크립트: `assets/build_v2.py`, `assets/render_bridge.py` (Python/Pillow/NumPy/SciPy 필요). 실행에는 Python이 필요하지 않습니다.

## 검증 범위

이벤트 조건·지속 시간·대응은 `node --test tests/events.test.js`로 검사할 수 있습니다.

브라우저 회귀 검사는 로컬 정적 서버의 하위 경로에서 실행합니다. Playwright와 Chromium을 설치한 환경에서 `python tests/browser_smoke.py`를 실행하세요. 설치된 Chromium 바이너리를 지정하려면 `CHROMIUM_BIN` 환경 변수를 사용합니다.

검사 범위는 데스크톱과 모바일 화면, 기존 9개 구역 및 신규 4개 유형 전환·관측 순회, 상황 발생 조건·대응·워프 종료, 함교 이동·모드 전환·폴백, 지도 선택·워프·방문 저장, 마리 보고·순찰·차·드론, 음향 합성·자동 관측 순회·복귀, 3D 시점 이동, 자동 접근·이탈과 중단, 거리 표시, 동작 줄이기 설정, 360° 입력, 관측 모드, GPU 컨텍스트 손실, 텍스처 메모리 오류, 3D 에셋 누락, 초기 로딩 재시도, 적응형 해상도입니다. 소프트웨어 WebGL로 검사하며 실제 GPU와 실물 모바일 하드웨어는 검증 범위 밖입니다.

## 그래픽 품질

항해 패널의 **그래픽 품질**에서 Auto, Ultra, High, Medium, Low, Compatibility를 선택합니다. 적용 에셋, 큐브 면 크기, 실제 캔버스 크기, 프레임 속도, 활성 WebGL 텍스처 수와 하향 사유를 볼 수 있습니다. 관측 장면의 주광원·대기·구름·반사는 시각적 근사입니다.

- Auto는 터치·저메모리 기기에서 Low로, 다른 기기에서 Medium으로 시작합니다. 프레임 시간에 따른 해상도 변경은 에셋 다운로드와 별개입니다.
- 32개 구역은 각각 Low 512px 및 Medium 1024px 큐브 면을 사용합니다. Nereid, Gaia, Deep Space, Nebula, Halo Gate에는 2048px High, 4096px Ultra 큐브와 별도로 생성한 8192×4096 원본을 포함합니다.
- Compatibility는 기존 360° 파노라마를 표시합니다. GPU 오류 시에는 Canvas 모드로 전환됩니다. 품질 창에서 에셋을 다시 불러오거나 취소할 수 있습니다. 출항 전 에셋을 불러오는 중이라면 Esc로도 취소할 수 있습니다.

에셋과 검증 절차는 [에셋 출처](ASSET_LICENSES.md) 및 [PR09 검증 보고서](qa/PR09_REPORT.md)에 정리했습니다.
