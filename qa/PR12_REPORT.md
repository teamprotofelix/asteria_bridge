# PR12 · Free Flight

기준 main `5156cff4b0f4632ad5452aa4867f925b0f3a14f3`, PR #11 병합 후.

- 자유 조종은 정적 우주 배경과 실시간 천체 렌더러의 카메라에 실제 구역 내 위치를 전달합니다. 구역 지도는 기존 가상 배치 좌표를 유지하고 조종 패널의 좌표와 속도는 SU 및 SU/s를 사용합니다.
- W/A/S/D와 Q/E로 피치·요·롤, I/K와 J/L, U/O로 전후·좌우·상하 이동합니다. 두 개의 터치 스틱과 상하·롤·제동 버튼을 제공합니다. 독립 시점의 드래그는 기수에 영향을 주지 않습니다. P 또는 Esc로 기존 관측 항로에 돌아옵니다.
- 120 Hz 적분, 120 ms 프레임 제한, 자세 정규화, 유한 구역 경계, 천체·위성·소행성·유적 여유 거리와 이동 선분 검사를 사용합니다. 고리는 통과 가능한 파편 구역으로 감속합니다. 콘솔의 접근·공전·거리 유지·이탈은 주 천체를 기준으로 작동합니다.
- 자동 항법은 계획 → 구역 내 기수 정렬 → 취소 가능한 에셋 준비 → 워프 → 도착 후 접근 순서입니다. 워프 진입 후에는 도착까지 진행합니다. 취소·로드 실패 시 출발 구역을 유지합니다. 지도에서 자동 항법 단계와 목적지, 워프 출발지·진행률, 도착 후 방문 기록을 확인할 수 있습니다.
- 기존 14종에 일몰, 위성 통과, 항성 플레어, 펄서 빔, 성운 난기류, 함대 조우, 접안 요청을 더했습니다. 행성·위성·빛 벡터로 자동 사건 후보를 고르며, 수동 연출은 별도로 선택할 수 있습니다.

`flight-pr12-captures`에는 Chromium 실행에서 생성한 자유 조종, 모바일 터치, 지도 및 신규 이벤트 장면을 저장합니다.

유적과 파편의 충돌 경계는 보수적인 구형 근사입니다. 공전 보조는 거리 유지·접선 추력으로 동작하며 궤도역학을 재현하지 않습니다. 일출·일몰·일식의 화면은 관측 연출이며, 접안 요청은 통신 이벤트입니다. 본 단계의 비행은 30개 실시간 3D 구역에서 사용 가능하고, 2개 파노라마 구역 및 Canvas에서는 기존 항해를 제공합니다. 실제 모바일 기기와 물리 GPU 성능은 미검증입니다.
