## 사용자 관리 프록시 계약

브라우저는 승인할 때만 JSON POST를 전송합니다. 페이로드는 `{snapshot:{sectorId,sectorName,mode,warning,eventName},text}`입니다. 플랫폼과 브라우저 연결 메타데이터는 HTTP 특성상 프록시에 노출될 수 있습니다. 과거 대화, 계정·방문 데이터, 저장된 선호, DOM, API 키는 전송 본문에 포함하지 않습니다. 브라우저는 쿠키·참조 페이지를 보내지 않으며 리디렉션을 허용하지 않습니다.

프록시는 해당 Pages 원본을 대상으로 CORS 설정을 제공하고 필요한 모델 인증을 서버에서 처리합니다. 응답은 최대 2048바이트의 JSON이며 `{"reply":"observe"}`, `{"reply":"report"}`, `{"reply":"guide"}`, `{"reply":"unavailable"}` 중 하나를 반환합니다. 화면에는 로컬에서 실제 함교 상태를 기반으로 만든 문장이 나타납니다. 프록시 응답에는 실행 명령, 자유 형식 답변, 링크 또는 스크립트가 허용되지 않습니다. 6.5초 제한, 취소 및 HTTP 429의 제한된 대기 시간을 적용합니다.

실제 프록시 구축과 모델 서비스 연결은 별도 범위입니다. 로컬 모드는 네트워크가 끊긴 뒤 이미 열린 기본 화면에서 사용할 수 있습니다. 오프라인 새로고침에 필요한 에셋 캐시는 PR14 범위입니다.
