# PR14 · Persistent Voyage

기준 main `cebe3c610171419de49504e8285df5db820d607e`, PR #13 병합 후.

## 저장과 복원

- 기본 세션 모드. **항해 일지 → 저장·백업**에서 이 브라우저 저장을 선택할 수 있습니다. 기존 방문 키는 그대로 보관하며 사용자가 가져올 때만 합칩니다. PR13의 별도 마리 기억 동의는 유지합니다.
- 스키마 v2는 구역 방문, 마지막 안전 구역, 관측 모드, 승인한 항로, 300건의 구조화 일지와 마리 선호 구역을 담습니다. 대화 필드는 비워 두며 메시지·프록시·토큰은 저장하거나 내보내지 않습니다. 현재 워프·경보·자유 조종 속도·자동 관측 실행 여부는 복원하지 않습니다.
- 백업은 최대 256KB이며 목록·형식·값을 검사한 뒤 미리보기에서 병합 또는 대체를 적용합니다. 현재 브라우저의 저장 동의가 우선합니다. 초기화는 재확인 후 새 스키마만 지웁니다. 저장소 한도 오류 시 기존 백업은 유지됩니다.
- Web Locks가 있으면 같은 원본의 업데이트를 직렬화하고, 각 변경은 최신 값을 기반으로 한 번에 커밋합니다. 탭 간 저장소 이벤트로 동기화합니다. Web Locks가 없는 브라우저의 동시 저장은 마지막 커밋이 우선이며 엄격한 동시 쓰기 직렬화는 제공하지 않습니다.
- 일지에는 출발·도착·관측·발견·드론·차·우주 상황을 기록합니다. 실제 컴퓨터 시각과 세션의 모의 시간을 별도로 표시하며, 구역·종류 검색 및 정렬을 지원합니다.

## 자동 관측

- 기존 8개 구역·45초 프리셋을 유지합니다. 맞춤 항로는 32개 중 1~32개 정거장의 순서, 정거장별 30~3600초, 1~99회 또는 무한 반복, 함교·함장석·라운지·외부 시야, 무음·기존 음향을 선택합니다.
- **이 항로로 관측 시작**으로 현재 편집본을 승인합니다. 도중 일시정지, 재개, 다음 구역, 종료를 제공합니다. 에셋 실패는 한 번 자동 재시도 후 대기합니다. 사용자가 다음 구역을 누르면 실패한 정거장을 건너뜁니다. 숨긴 탭은 관측 카운트다운과 음향을 멈춥니다.
- 워프를 이미 시작한 경우 해당 워프를 마치고 추가 이동을 중지합니다. 새로고침은 마지막 안전 구역을 관측 모드로 엽니다. 화면 유지 API를 호출하거나 백그라운드 수행을 보장하지 않습니다.

## PWA

- 서비스 워커는 상대경로 배포를 지원합니다. 설치 시 셸과 NEREID 기본 에셋을 캐시합니다. 셸·기본 에셋·사용자가 내려받은 구역은 캐시 우선이며 이외 에셋은 네트워크에서 가져옵니다. 외부 요청과 POST는 서비스 워커가 가로채지 않습니다.
- 추가 구역은 Low/Medium 배경, 필요한 표면과 기존 폴백을 선택 다운로드합니다. 한 구역 최대 8MiB, 전체 추가 캐시 24MiB입니다. 오래 사용하지 않은 구역을 제거하며 실제 크기와 수동 삭제를 제공합니다.
- 신규 셸이 준비되면 사용자가 적용합니다. 현재 함교가 이동 중이거나 같은 배포 범위에 다른 탭이 열려 있으면 적용을 제한합니다. 버전이 바뀌면 이전 구역 캐시를 정리하므로 추가 구역은 다시 내려받을 수 있습니다.
